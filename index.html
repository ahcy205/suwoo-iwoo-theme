보냈어요. 채팅방에서 링크를 누르면 설치돼요.
  1. 단추를 누르고 공유 목록에서 카카오톡을 골라요
  2. 나와의 채팅(아무 채팅방이나 괜찮아요)으로 보내요
  3. 채팅방에서 보낸 링크를 누르면 "테마 다운로드 완료"
  4. 더보기 → 설정(⚙) → 테마에서 우리 두 조카를 골라요

카카오톡 안에서는 안드로이드 테마 파일을 받을 수 없어요. 크롬이나 삼성 인터넷으로 열어 주세요.

다른 브라우저로 열기
복사했어요. 크롬이나 삼성 인터넷 주소창에 붙여 넣어요.

받기 전에 두 가지만

이 테마는 권한을 하나도 요구하지 않는 그림과 색 모음이에요. 그래도 안드로이드는 플레이스토어 밖에서 받은 앱을 막아서, 잠깐 허용해야 해요.

  1. 삼성 갤럭시라면 보안 위험 자동 차단을 잠깐 꺼요
    설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단 → 끔
    요즘 갤럭시는 처음부터 켜져 있어요. 켜져 있으면 2번을 해도 설치가 막혀요.
  2. 지금 쓰는 브라우저에 출처를 알 수 없는 앱 설치를 허용해요
    설정 → 보안 및 개인정보 보호 → 기타 보안 설정 → 출처를 알 수 없는 앱 설치
    목록에서 이 페이지를 연 브라우저(크롬 · 삼성 인터넷)를 골라 켜요.
